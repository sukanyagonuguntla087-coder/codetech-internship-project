
# Social Media Graph Analysis

## Objective
To analyze connections between users in a social network using graph theory.

## Technologies Used
- Python
- NetworkX
- Matplotlib

## Features
- Create a social network graph
- Count users and connections
- Identify the most connected user
- Find mutual friends
- Visualize the social network

## Conclusion
This project demonstrates how graph analysis can
help understand relationships and connections
between users on social media.
